{%- comment -%} An image, with smaller and modern-format copies when they exist. With an entry in _data/responsive.json (npm run images), it's a offering AVIF and WebP at several widths, and the browser picks the smallest that fills the slot; the original stays as the fallback . Without one, it's the plain . Either way the gets its width and height. The is display: contents (.pic), so layout and styles treat the as if it sat directly in the parent. Params: path URL path of the original ("/assets/img/ALCF/ar.jpg") alt alt text sizes how wide the image shows, as a sizes attribute (default 100vw) attrs extra attributes for the ('loading="lazy" data-reveal') class class for the {%- endcomment -%} {%- assign r = site.data.responsive[include.path] -%} {%- capture pic_img -%} {%- endcapture -%} {%- if r -%} {%- assign pic_formats = "avif,webp" | split: "," -%} {%- for fmt in pic_formats -%} {%- endfor -%} {{ pic_img }} {%- else -%} {{ pic_img }} {%- endif -%}
