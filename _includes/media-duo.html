{%- comment -%} Two-up media. Slots a,b. Each accepts src_x / video_x / alt_x / caption_x. Add autoplay_x=true to a video slot for a muted, looping video that starts on its own, with a pause button (see transitions.js); alt_x becomes its label. Images and videos get a hairline border: border=false leaves it off for both slots, border_x=false (or true) sets it for one slot. caption (no suffix) captions the pair instead of a slot: the two items keep their columns and one caption runs under both. Use it when the point is the relationship between the two, not what either one is. Don't mix it with caption_a / caption_b. Empty slot renders a placeholder. See README for copy-paste usage. {%- endcomment -%} {%- assign shared = include.caption -%} {%- if shared -%} {%- else -%} {%- endif -%}
