{%- comment -%} Horizontal slider: a scrollable rail of mixed slides, advanced by the arrow buttons, a trackpad, a swipe, or the arrow keys when the rail has focus. Slides come from front matter, so one slider can mix images, videos and social posts. Each item takes one of: image: "USF/apple.png" + alt, caption, link, border (false drops the hairline) video: "/assets/video/x.mp4" + alt, caption, autoplay (muted, looping) tweet: { author, handle, date, datetime, url, text, src, alt } Params: items (required), label (names the region for screen readers). Usage: {% include slider.html items=page.recognition_slides label="Recognition" %} {%- endcomment -%} {%- assign items = include.items -%} {%- if items and items != empty -%}
