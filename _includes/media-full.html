{%- comment -%} Full-width media. Pass src + alt + caption for an image, or video + caption for a clip. Add autoplay=true to a video for a muted, looping video that starts on its own, with a pause button (see transitions.js); alt becomes its label. With no src/video it renders a labelled placeholder (wireframe). Images and videos get a hairline border; border=false leaves it off. See README for copy-paste usage. {%- endcomment -%}
